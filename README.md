# Pharmacy Desk

Учебное настольное приложение на WPF для демонстрации пользовательских сценариев аптеки.

## Разделы приложения

- Регистрация и авторизация.
- Личный кабинет.
- Просмотр склада и списка сотрудников.
- Оформление доставки и отображение статуса заказа.

## Технологии

C#, WPF, Entity Framework Core, SQLite, Material Design in XAML.

## Запуск

Откройте `WpfApp2.sln` в Visual Studio с установленной поддержкой WPF и соберите проект. SQLite-файл в репозитории пустой; для локальной работы приложение создаст или использует свою базу.

Это учебный прототип. Не используйте его для реальных заказов, учетных записей или персональных данных.
